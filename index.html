Copies your YaVeen as a picture, so it looks like your symbols anywhere you paste it: iMessage, Notes, Instagram, email. Use Light ink for dark-mode chats.

Each digit is built from countable strokes: arches on top are worth 4 (at most two), sticks standing on the beam are worth 1 (at most three), and an empty ring is zero. So a digit's value is 4 × arches + sticks. To add, pour the strokes together: 4 sticks fuse into 1 arch and 3 arches fuse into a carry (one stick in the next place left). Place values are 1, 12, 144, 1728… Thirds and quarters terminate: ⅓ = 0·4 (one arch), ½ = 0·6, ¼ = 0·3. Switch the input to Numbers mode and type decimal numbers or sums like 23+19 to see them in YaVeen.
The Copy symbols (image) button works everywhere. To type in YaVeen inside apps, install the font:
Download yaveen.otf iPhone font profile (.mobileconfig) yaveen.ttf
  • iPhone, profile: open this page in Safari, tap iPhone font profile and choose Allow. Then open Settings → Profile Downloaded (or General → VPN & Device Management) and tap Install. iOS asks you to approve it and marks it “Not Verified” because it is unsigned. That is expected. If Safari saves the file to Files instead, open it from Files → Downloads, then go to Settings.
  • iPhone, app: or download yaveen.otf and open it in a font-installer app such as iFont, then install it from there.
  • Then pick YaVeen in the font menu of Pages, Keynote, Word and other apps with a font picker. Messages, Notes and social apps can’t use custom fonts, so use Copy symbols (image) there. To remove the font, go to Settings → General → VPN & Device Management.
Install yaveen.ttf or yaveen.otf and any English text set in the YaVeen font appears as YaVeen letters: A–Z give the drawn capitals, a–z the lowercase. Private Use Area: capitals U+E000–U+E019, lowercase U+E020–U+E039, digit ten U+E040, eleven U+E041, dozenal point U+E042, negative sign U+E043, + − × ÷ = at U+E044–U+E048.
Numbers: typing ASCII digits 0–9 in the font only swaps each digit for a YaVeen digit glyph; it does not convert the value to base 12 (so typing “12” shows one-two, which in YaVeen means fourteen). Use the Numbers mode above to convert decimal values properly.
